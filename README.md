Walmart Sales Analysis Dashboard (2015–2018)
Project Description

This project analyzes Walmart sales performance across four years using Excel to uncover insights around revenue growth, customer loyalty, shipping methods, and regional sales.

Objectives
Analyze yearly sales growth,
Identify top-performing regions and states,
Evaluate customer loyalty impact,
Understand product and shipping performance.

Tools Used
Excel,
Pivot Tables,
Charts & Visualizations,
Interactive Dashboard

Key Insights
Technology led revenue generation,
California was the strongest sales state,
Standard Class was the best-performing shipping mode,
Loyal customers significantly impacted revenue

Recommendations
Invest in top-performing categories,
Improve customer retention programs,
Optimize shipping operations,
Replicate successful regional strategies.
